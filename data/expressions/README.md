# 官方表情差分（`data/expressions/`）

> 这个目录**默认只带 7 张项目自带的占位/遮罩 PNG**（`eyes_closed/half/wide`、`mouth_line/open`、`eye_mask*`，用于默认眨眼与口型），官方表情差分需要你自行放入。表情系统在缺图时会自动降级：只变嘴型、保持默认眼，不报错、不白屏。官方差分文件（`eyes_happy.png` 等）已被 `.gitignore` 排除，请不要提交。

## 需要放什么

从官方资源里提取的表情差分，文件名固定（改名字不会被加载）：

| 文件 | 内容 | 用途 |
|---|---|---|
| `eyes_happy.png` | 弯眼 | `emotion=happy` |
| `eyes_shy.png` | 害羞 / 半闭眼 | `emotion=shy`、`emotion=sleepy` |
| `eyes_sad.png` | 沮丧 / 垂眼 | `emotion=sad` |
| `eyes_surprised.png` | 睁大眼 | `emotion=surprised` |
| `blush.png` | 半透明红晕 | `happy`（轻）/ `shy`（重） |

## 图片要求

- **PNG，带透明通道**；透明处不会被绘制（原贴图透出来）。
- **单眼图**（宽高比 < 1.6）：一张图用于左右两只眼——这是推荐形式，因为本模型
  **左右眼共用同一块 UV**（ADR 0026 的资产事实），左右不对称的画法在贴图上无法区分。
- **双眼条**（宽高比 ≥ 1.6）：按左半/右半切分；由于共用 UV，实际会用左半（契约里写明了这个限制）。
- 建议 128×128 或 256×256，眼睛大致居中铺满画布（留 5%–10% 边距）。
- `blush.png`：一张柔边粉色斑块，左右两个脸颊都会用同一张（各自独立采样）。

## 怎么用

1. 把 5 个文件放进本目录；
2. 重启桌宠（`npm.cmd start`）；
3. 启动日志会打出 `[render] 表情差分：eyes=4/4 blush=true missing=(none)`；
4. 自检 `npm run selftest` 会额外断言"贴图真的变了 + 恢复后完全还原"。

目录可用 `PET_EXPRESSIONS_DIR` 覆盖（相对路径按工程根解析）。

## 关于 `data/expressions.fixtures/`

那是**管线自测用的非官方 fixture**（用简单矢量形状生成、只为验证"图片 → 贴图"这条路走得通），
**不是官方美术**。正式使用请用官方差分覆盖本目录，而不是 fixture 目录。

## 实测的映射事实（2026-10-31，离线复现运行时栅格化）

| 项 | 实测值 | 对出图的影响 |
|---|---|---|
| 单眼表面像素数 | 584,730 | 差分图不必很大：128×128 足够 |
| 局部坐标覆盖的面空间 | 宽 3.94e-4 × 高 1.24e-4（模型单位） | 归一化窗口 ≈ **虹膜区域** |
| **拉伸比（宽:高）** | **3.18 : 1** | 方形眼图会被横向拉宽 3 倍；官方贴图空间的裁剪正好适配 |
| 1%/99% 之外的像素 | 3.6%（夹取到边缘，不丢弃） | 眼区边缘不会留原虹膜 |

因此出图建议：**画布横向铺满、图案集中在垂直中段**；若手绘，按 3:1 的横向比例画（例如 384×128）。
