# 0046. 真机截图三问：死鱼眼 / 手写眨眼 / 微侧身与嘴型

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-11-05 |
| 决策者 | 项目所有者（真机截图：眼神呆滞看地、眨眼像翻白眼、嘴巴仍微张；建议坐姿微侧身） |
| 关联 | 契约 §5.2（表情/嘴型）、§7.3（render 表现规则）、§11（降级）；ADR 0010 D2.6（嘴型图集）、ADR 0014（骨骼仲裁）、ADR 0026 D6.6（表情只走贴图）、ADR 0044（停帧 + 程序化微动，**D4 被本 ADR 废止**）、ADR 0045（头部基准、张望） |

## 背景

上一轮（ADR 0045）把"坐姿低头"按头部基准修掉了，但真机截图仍然三处不对：

1. **死鱼眼**：头抬起来了，**眼球还是向下看**；
2. **眨眼像翻白眼**：闭眼瞬间下眼皮被硬拉上去；
3. **嘴巴仍微张**（一个小圆），且建议**坐姿微侧身**，不要正面死板对镜头。

## 排查

### 1. 死鱼眼：眼骨里也有一份"向下看"

ADR 0045 只接管了**头骨**（把世界朝向重置到绑定姿态）。眼球是头骨的子骨，
官方坐姿片段里眼骨自己带一个向下旋转 —— 停帧后 Mixer 不再写它，这份旋转就永久保留。
本轮实测：**片段眼球低头 = +0.262rad（15°）**，和头骨那份几乎一样大。

我们原来对眼球只做"张望 × 0.35"的加法，等于在"向下 15°"上再叠一点点，
所以头抬起来了、瞳孔还是压在下面 —— 就是"死鱼眼"。

### 2. 翻白眼：停帧下眼皮只能平移，不能转

ADR 0044 D4 用 `bone_eye_D_L/R.translation.x` 手写眨眼。站姿时这套能用，是因为
`Cafe_Idle` 的眨眼是**整段动画**（眼皮平移 + 上下眼皮子骨的旋转 + 混合）。
停帧之后只剩我们这一条平移通道：

- 眼皮是**下眼皮**的子骨，平移方向是本地 x，放大到 0.00028 时整片眼皮被推上去；
- 没有动画混合、没有上眼皮配合 → 读作"下眼皮硬拉上去"，也就是翻白眼。

这不是调参能救的：停帧状态根本没有"闭合"所需的联动通道。

### 3. 嘴型：`small` 映射到的是**大圆张口**

逐帧目视复核 `Character_Mouth_High-BgFqI_9W.png`（8×8）：

| 帧 | 形状 | 语义 |
|---|---|---|
| 0 | 平直细线 | 抿嘴（闭嘴） |
| 7 | 上扬小弧 | 微笑（闭嘴） |
| 8 | 下垂弧 | 不满（闭嘴） |
| 14 / 6 | 小/扁椭圆 | 微张 |
| 1 / 4 / 9 | 圆/椭圆张口 | 张口 |
| 2 | 宽张（白齿） | 明显张口 |

`EMOTION_MOUTH_FRAMES.small` 原来是 **9**（大圆张口），而 `shy` / `angry` / `sleepy`
都用 `small`，且表情嘴型按 **0.62 底板宽**绘制 —— 于是"害羞/无表情"时脸上挂着一个
明显的小圆。上一轮把静态帧从 0 改成 7 也没救：7 是弧线，在 0.62 尺寸下同样会被看成小圆。

### 4. 侧身：正面 0° 像证件照

停帧姿态 + 完全回正的头部 + 正面身体 = 证件照。用户建议"微微侧坐"。

## 决策

### D1 接管眼球：基底换成绑定姿态，再叠张望

- 模型加载时、`setupAnimations()` 之前采一次 `eyeBindLocal`（左右眼共用）。
- `BoneArbiter` 新增 `overrideBase(bone, quaternion | null)`：`endFrame()` 从**固定基底**
  开始合成（`final = yawQ·pitchQ·rollQ·overrideBase`），而不是从动画基底开始；
  零偏移时也写（否则要等第一个非零张望才生效）。
- 坐姿 `applySitMotion()`：`overrideBase(eye, eyeBindLocal)` + `add(eye, gazeYaw×0.35, gazePitch×0.35)`。
- 退出坐姿：`overrideBase(eye, null)` 不需要显式调用 —— `sitMotion` 包络归零后不再提交眼球偏移，
  站姿的 Mixer 会重新写眼骨（`beginFrame` 判定 `mixer` 基底）。

实测：片段眼球低头 **+0.262rad** → 接管后 5s 眼球俯仰均值 **-0.05rad（平视）**，
且与头骨朝向差 < 0.2rad（跟着头转）。

### D2 删除全部手写眨眼

**硬约束：不再用代码碰眼皮骨（`bone_eye_D_*`）的任何通道。**

- `bone-arbiter`：删除 `addPosition()` 与整条位置偏移通道（`basePos/posOffset` 等）。
- `sit-motion`：删除 `blinkEnvelope` / 眨眼排期 / `blink` / `blinkOffset` / `blinkNow`。
- `render-module`：删除 `debugBlink()`、眼皮骨分支、`warnedMissingEyelids`。
- `main.ts` / `globals.d.ts`：删除 `forceBlink` 调试接口。
- 自检：删除 3 条眨眼断言与 `sit-blink-*.png` 取证，换成"眼骨只走旋转基底覆写"的结构级断言。

**坐姿下不再眨眼**：灵动感由呼吸 + 张望 + 晃腿承担。站姿的眨眼仍由官方 `Cafe_Idle` 动画提供
（那段是完整动画，不需要我们插手）。

### D3 微侧身 + 嘴型

**D3.1 微侧身**：`SIT_BODY_YAW_RAD = 0.15`（≈8.6°），加在 `animationRoot.rotation.y`，
按 `sitGain` 淡入淡出。头部基准必须在**未侧身**的坐标系里量：
`captureSitHeadLevel()` 用 `removeBodyYaw(world, sitBodyYaw)` 先扣掉这 0.15，
否则补偿会把侧身一起转回去（脖子拧着看镜头）。

**D3.2 嘴型**：
- `MOUTH_FRAME_CLOSED` 7 → **0**（平直细线，一眼就是闭嘴）；`staticFrameIndex` 同步为 0。
- `mouthWidthRatio` 0.24 → **0.32**：闭嘴线在 8–11px 宽时仍然可见。
- 表情嘴型重映射（全部仍是官方图集帧）：

  | 表情嘴 | 旧帧 | 新帧 | 理由 |
  |---|---|---|---|
  | `smile` | 7 | 7 | 上扬小弧，闭着 |
  | `frown` | 0 | **8** | 下垂弧才是"不满"，0 是平线 |
  | `small` | 9 | **0** | 9 是大圆张口（"常驻微张"的元凶） |
  | `open` | 4 | **2** | 惊讶要真的张开（白齿） |
  | `none` | 0 | 0 | 不画（owner=static） |

## 替代方案

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 只加大眼球张望幅度 | 不动眼骨 | 片段那份 15° 低头还在，只是"看得更用力" | 否 |
| 用贴图叠加画闭眼线 | 不碰骨骼 | ADR 0026 D6.6 禁止程序化绘制眼型；官方差分图缺失 | 否 |
| 用 `Cafe_Idle` 眨眼特征做极短切换 | 官方素材 | 停帧姿态与站姿姿态不同源，切换会跳；混合权重也会把坐姿打断 | 否 |
| 坐姿放弃眨眼（本方案） | 零风险、零骨骼写入 | 坐姿没有眨眼 | **是** |
| 侧身加在骨盆骨上 | 更" anatomically" | 骨盆在片段里有自己的动画，仲裁器加偏航会与头部基准互相纠缠 | 否（加在根节点） |
| 闭嘴继续用 7 号弧线 | 有一点笑意 | 在 0.62 表情尺寸下仍像小圆 | 否（0 号平线） |

## 后果

**正面**

- 眼球平视：片段低头 +0.262rad → 接管后均值 -0.05rad，且跟随头部张望（差 <0.2rad）。
- 不再翻白眼：眼皮骨位移通道**整条删除**，代码层面写不出来。
- 嘴型：静音/无表情是平直细线；微笑/不满是闭着的弧线；只有"惊讶"才张口。
- 坐姿微侧身 8.6°，不再是证件照正面。
- 单测：`bone-arbiter` 6 条（新增基底覆写 2 条、删除位置偏移 3 条）、`sit-motion` 9 条
  （删除眨眼 2 条、新增"无眨眼字段" 1 条）、`speech` 口型 5 条、`facial-texture` 静态帧 1 条。

**负面 / 成本**

- 坐姿没有眨眼：长时间静止时少了一个"活"的信号（用张望/晃腿补偿）。
- 表情嘴型尺寸 0.62 是经验值；换图集要重新逐帧核对（帧序不是标准 viseme 表）。
- 侧身是根节点偏航：掩膜与命中区跟着转，属预期；`sitOffsetPx` 的补偿量仍按未侧身的包围盒算，
  侧身带来的水平位移 <2px（模型在 z 方向很薄）。

**约束**

- 不得用代码写眼皮骨（`bone_eye_D_*`）的任何通道。
- 不得新增状态名、事件、`intent`、`emotion`、IPC 通道或 `RenderState` 字段；
  `sit.eyeOrientation` / `sit.eyeRawPitch` / `sit.bodyYaw` 都是内部诊断。
- 嘴型只能来自官方图集帧；帧号必须逐帧目视核对（0/7/8/2/9 的语义见上表）。
- 所有幅度/周期只写在 `shared/constants.ts`。
