# 0045. 真机四问：开局转圈 / 坐姿低头 / 上半身僵硬 / 嘴型

| 项 | 值 |
|---|---|
| 状态 | 已接受 |
| 日期 | 2026-11-04 |
| 决策者 | 项目所有者（真机验收：开局转圈、坐姿一直看下方、上半身像雕塑、嘴常驻微张且只有一张嘴） |
| 关联 | 契约 §4.1（`idle`）、§5.2（表情/嘴型）、§7.3（render 表现规则）、§11（降级）；ADR 0015 D4（TTS 包络 → 口型）、ADR 0023 D5 / ADR 0041 D4（待机与空闲小动作）、ADR 0043 D1（启动冷却）、ADR 0044（坐姿停帧 + 程序化微动，**D3/D5 被本 ADR 调整**）、ADR 0010 D2.6（嘴型图集） |

## 背景

一轮真机验收提出四个具体问题，本轮全部修掉：

1. **开局转圈**：启动后她原地偏航 360°，像陀螺（ADR 0043 D1 只压住了"什么时候触发"，没解决"这个动作本身不该存在"）。
2. **坐姿一直看下方**：官方坐姿停帧自带"低头沉思"，程序化张望直接叠在这个低头底座上。
3. **坐姿像雕塑**：只有脊柱在呼吸，肩线/手臂完全不动；晃腿幅度 0.08rad 在真机上几乎看不见。
4. **嘴型**：不开口时嘴是微张的；说话时只有一张嘴（包络电平稳定 → 连续量化停在同一帧）。

硬约束不变：**零按次计费**（C-1），所有修复都必须落在本地渲染/本地音频路径上。

## 排查

### 1. 转圈：不是"什么时候播"，而是"不该播"

`fidget` 原来有两个分支：官方片段 `shy`（`Cafe_Reaction` 3.2–4.9s）与程序化 `spin`
（纯根节点偏航 0→2π，梯形速度曲线 1.7s）。ADR 0043 D1 把"启动后 45s 冷却"做对了，
但**动作本身**仍在：一个没有重心转移、没有脚步的角色原地偏航 360°，读起来就是"贴图在转"。

### 2. 低头：量到的不是"头骨本地旋转"，也不是"头骨世界欧拉角"

坐姿停帧（14.5–14.7s）里骨盆后坐、脊柱前倾、颈前伸，最后头骨再低一点。
只抵消头骨**本地**四元数会剩下一半低头（脊柱那一份还在）。

但**头骨世界四元数的欧拉角也不能直接用**：3ds Max 导出的骨骼带任意 rest 朝向，
绝对欧拉角里混着绑定姿态的偏转（本资产实测 x ≈ -0.20rad）。
第一版实现（拿世界 pitch 当"低头量"）在自检里露馅：标定出的"低头"只有 0.073rad，
而抵消后头骨反而更低了——量到的根本不是"她低了多少头"。

正确口径是**相对绑定姿态的旋转差**：

```
delta = worldSit · worldBind⁻¹      // 从"平视"到"坐姿停帧"转了多少
correction = delta⁻¹                 // 抵消量（YXZ 拆成 yaw/pitch/roll）
```

实测 delta 的欧拉角 ≈ pitch **+0.262**（低头 15°）、yaw +0.408、roll -0.151 —— 这才是"低头沉思"。

排查中还发现第二个坑：停帧后 Mixer 不再重写骨骼，`bone.quaternion` 里是我们上一帧
写出的最终值（含张望）。必须读 `BoneArbiter.animationBase()`（动画基底），否则会把
"张望"当成"片段低头"一起抵消。

### 3. 僵硬：肩线是"停帧后唯一完全静止的大块"

停帧后呼吸只剩脊柱 ±0.006rad。肩/上臂一动不动，整条上半身读作一块板。
晃腿的问题不是"没有"，而是 0.08rad（≈4.6°）在 480×720 窗口里只有 2–3px，且左右严格对称、
严格反相 → 节拍器。

### 4. 嘴型：两个独立的 bug

- **静态帧被夹成 0**：`drawAtlasFrame(layout.staticFrameIndex, 1)` 想表达"只画静态帧"，
  但函数内部 `index = min(frameIndex, count-1)`，`count=1` 把**任何**帧号都压成 0。
  0 号帧是一根极细的横线，缩小到 10–15px 后几乎不可见；真机上看到的是"嘴没了/嘴不对"。
- **只有一张嘴**：`levelToFrame = round(level·7)` 是连续量化。本机 TTS 的 RMS 很平，
  一句话里电平只在 0.85–1.0 之间抖，量化后**永远是同一帧**。
- 图集帧序（`Character_Mouth_High-BgFqI_9W.png`，8×8，本轮逐帧目视复核）：
  `0` 极细横线 / `1` 大椭圆 / `2` 扁宽张口 / `3` 高圆张口 / `4` 中椭圆 / `6` 扁小椭圆 /
  `7` 小弧线（闭）/ `8` 下弯弧 / `9` 高圆张口 / `14` 扁小椭圆。

## 决策

### D1 删除 `spin`：空闲小动作只剩官方片段

- `fidget.ts` 不再有转圈曲线；只保留**排期**（`nextFidgetDelayMs` / `nextFidgetAtMs`，
  含 ADR 0043 D1 的 45s 硬冷却）。
- `render-module.updateFidget()` 只尝试 `playOnce('fidget.shy')`；**片段缺失就什么都不做**，
  不回退到任何程序化动作（同一理由：ADR 0039 D2 已因"手写骨骼"删掉程序化摸头）。
- 诊断 `RenderDiagnostics.fidget.kind` 收窄为 `'shy'`，`yaw` 字段保留但恒为 0（不破坏形状）。
- **不做**"歪头/踮脚"这类新程序化小动作：没有官方片段支撑的手写姿态，上一轮已经被否过一次。

### D2 坐姿头部基准：相对绑定姿态量一次，之后每帧抵消

1. **参照**：模型加载后、`setupAnimations()` **之前**采一次头骨**绑定姿态**的世界朝向
   （`headBindWorld`）。它是"平视前方"的锚点——骨骼 rest 朝向任意，只有相对量有意义。
2. **标定时机**：`enterSit` 之后、`playHold('sit')` 的片段权重 ≥ 0.95 的第一帧
   （淡入中途是"站姿与坐姿的混合"，量出来没有意义）。
3. **量什么**：`delta = worldSit · worldBind⁻¹`，其中 `worldSit` 由
   `BoneArbiter.animationBase(head)`（动画基底，不含我们自己的偏移）× 父骨骼世界朝向合成。
4. **抵消量**：`delta⁻¹` 按 YXZ 拆成 `(yaw, pitch, roll)`，交给 `arbiter.add(head, …)`。
   仲裁器的合成顺序 `yawQ·pitchQ·rollQ·base` 正好等于 YXZ，所以最终世界朝向 = 绑定姿态。
   夹取 |pitch| > 0.6rad 时**不修**（说明骨架朝向异常，宁可不修）。
5. **淡入**：抵消量乘 `frame.gain`（0→1 的 500ms 包络），标定完成的那一帧不会"啪"地抬头；
   离开坐姿也不硬清零，跟着包络淡出。
6. **张望目标**（`sit-motion.pickGazeTarget`）：
   - 水平 `±SIT_GAZE_YAW_RAD = 0.36`；
   - **偏向抬头**：72% 概率取 `-(0.06–0.22)`，28% 取 `+0–0.06`（往下瞄一眼）；
   - 保持 2.2–4.2s 换一次（比上一版 3–6s 更勤）。
7. **过渡**：固定时长的 `easeInOutCubic`（220–420ms），**不再用指数阻尼**——
   阻尼是"越接近越慢"，观感像"慢慢飘过去"；cubic 是"起步→加速→收住"，才像一次干脆的转头。

### D3 上半身与晃腿：肩膀呼吸 + 不对称摆腿

| 量 | 参数 | 说明 |
|---|---|---|
| 锁骨 | `SIT_BREATH_SHOULDER_RAD = 0.02` | 与 sin 同相 |
| 上臂 | 同幅、相位领先 90°（cos） | 错开相位才不会读成"耸肩" |
| 大腿 | `SIT_LEG_THIGH_RAD = 0.17` | 0.08 → 0.17（≈9.7°），真机可见 |
| 小腿 | `SIT_LEG_CALF_RAD = 大腿 × 0.8 = 0.136` | 膝盖折得比上一版明显 |
| 速度 | `SIT_LEG_SWING_RAD_PER_SEC = 2.6` | 一个来回 ≈2.4s |
| 左右速度差 | `SIT_LEG_RATE_SKEW = 0.05` | 左 ×1.05、右 ×0.95 → 相位缓慢漂移 |
| 左右幅度差 | `SIT_LEG_AMP_SKEW_R = 0.9` | 左腿是"主腿"，抬得高一点 |
| 包络幂次 | `LIFT_POWER_L = 0.66` / `_R = 0.82` | 左快起快落、右慢起慢落 |
| 膝盖滞后 | `SIT_LEG_CALF_LAG_RAD = 0.32` | 膝盖比大腿晚 ~70ms 折起来 |

- 仍然只往"抬"的方向摆（`0.5-0.5cos` 单峰）：坐姿把靴底钉在窗口底边，往下摆会穿出窗口。
- 小腿滞后也只在"折"的方向（正 pitch），所以脚**任何时刻都不低于静止姿态**。

### D4 嘴型：静态闭嘴帧 + 四档元音

1. **静态闭嘴**：`CH0335_MOUTH_LAYOUT.staticFrameIndex = 7`（小弧线），且
   `drawAtlasFrame` 必须拿到**真实帧数**（`columns × rows`）。新增纯函数
   `atlasFrameIndex(frameIndex, frameCount, columns, rows)` 作为回归点。
   `MOUTH_FRAME_CLOSED` 同步从 0 改为 7（0 号帧是极细横线，缩小后不可见）。
2. **四档元音**（`mouth-mapping.ts`）：

   | 电平 | 档 | 帧 | 观感 |
   |---|---|---|---|
   | < 0.12 | 闭 | 7 | 闭嘴弧线 |
   | < 0.40 | 微张 | 6 / 14 交替 | 嘴唇刚分开 |
   | < 0.72 | 中张 | 1 / 3 交替 | a/o 之间 |
   | ≥ 0.72 | 大张 | 2 / 9 交替 | 明显张口 |

   档内每 `MOUTH_VISEME_SLOT_MS = 180ms` 换一张 → **同一电平也在动**，长句读起来是嘴在开合，
   而不是"一张嘴忽大忽小"。30Hz 的重绘上限（`MOUTH_UPDATE_MIN_INTERVAL_MS = 33`）不变。
3. 嘴层仲裁不变：说话/口型驱动 > 表情嘴型 > 静态闭嘴（`resolveMouthOwner`）。

## 替代方案

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 保留转圈、只把间隔拉长 | 改动最小 | 动作本身出戏，用户明确否决 | 否 |
| 用"歪头/踮脚"替代转圈 | 不依赖片段 | 手写骨骼姿态已被 ADR 0039 D2 否过一次 | 否（直接停用） |
| 只抵消头骨本地四元数 | 实现简单 | 漏掉脊柱/骨盆的前倾，仍会低头 | 否 |
| 用头骨世界欧拉角当"低头量" | 不用采绑定姿态 | 骨骼 rest 朝向混在里面（实测 -0.20rad），第一版就是这样量错的 | 否（用相对绑定姿态的 delta） |
| 标定时读 `bone.quaternion` | 少一个接口 | 停帧后读到的是上一帧最终值（含张望），越跑越偏 | 否（用 `animationBase()`） |
| 张望继续用指数阻尼 | 不用记"起点/时长" | 观感"慢慢飘"，用户要求干脆 | 否（easeInOutCubic） |
| 晃腿继续 0.08rad 对称 | 保守 | 真机看不见、像节拍器 | 否 |
| 口型继续 `round(level·7)` | 连续、简单 | 稳定电平下永远同一帧 | 否（四档 + 档内轮换） |
| **本轮方案（D1–D4）** | 全部有真机证据、参数集中、零新状态 | 需要按资产标定头部 pitch 与图集帧 | **是** |

## 后果

**正面**

- 开局不再转圈：`fidget` 只剩官方 `shy` 片段，片段缺失时**什么都不做**。
- 坐姿抬头：标定后基准被重置为"平视前方"，张望在 ±0.36/±0.22 内干脆地转，抬头占多数。
  实测：片段自带低头 **+0.263rad**（15°）→ 抵消 **-0.250rad** → 5s 采样头骨相对绑定姿态
  的均值 **-0.03rad**（平视），yaw 摆幅 **0.45–0.52rad**。
- 上半身有肩线起伏（±0.02rad）、晃腿 0.17rad 且左右不对称（速度/幅度/包络/膝盖滞后四项）。
- 不开口时是清楚的闭嘴弧线；说话时在 4 档 6 张官方帧之间切换
  （自检实测轨迹 `7→1→3→2→9`）。
- 新增/扩写单测 4 组（`sit-head` 4 条、`sit-motion` 10 条、`speech` 口型 5 条、
  `facial-texture` 静态帧 1 条）；主链路自检 +3 条、语音自检 +4 条真机断言
  （含"五帧嘴型各自不同"的截图像素差取证）。

**负面 / 成本**

- 头部基准是**一次性标定**：换模型或换坐姿片段必须重新看 `headRawPitch` 是否合理（±0.6 夹取）。
- 四档元音是离散的，档位边界（0.12/0.40/0.72）是经验值；换 TTS 音色可能要重调。
- 左右不对称让两条腿的相位会漂移：极少数时刻会接近同相（观感是"两条腿一起荡"，可接受）。

**约束**

- 不得新增状态名、事件、`intent`、`emotion`、IPC 通道或 `RenderState` 字段；
  `sit.motion` / `sit.headRawPitch` / `sit.headOrientation` 都是内部诊断。
- 空闲小动作只允许官方片段；**禁止**为它新增程序化骨骼/根变换。
- 嘴型只能来自官方图集帧（ADR 0026 D6.6：每个像素都必须来自图片）。
- 所有幅度/周期只写在 `shared/constants.ts`。
